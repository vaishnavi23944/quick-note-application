# Quick Note Application

A beginner-friendly notes web app built with HTML, CSS, and vanilla JavaScript.

## Features
- Create notes with a title and description
- Edit and delete notes
- Search notes by title or content
- Browser persistence with `localStorage`
- Responsive desktop and mobile layout
- Basic input validation and delete confirmation

## Run locally
1. Download or clone this project.
2. Open `index.html` in a modern browser.
3. Create a note and refresh the page to check that it is saved.

No build tools or dependencies are required.

## Deploy with GitHub Pages
1. Create a public repository on GitHub named `quick-note-application`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for deployment and open the URL shown on the Pages settings screen.

## Storage note
Notes are stored in the current browser's local storage. They do not sync between devices and may be removed if browser data is cleared. Do not store passwords or sensitive information.

## Technologies
HTML5 · CSS3 · JavaScript · Browser localStorage · GitHub Pages
